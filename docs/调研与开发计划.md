## 二、产品定位与核心设计

### 核心理念
**图 = 数据 + 代码 + 风格预设 + 会话**。用户始终面对直观界面（图片预览 + 对话 + 参数卡片），代码在后台生成、在"代码定位面板"中以**可解释、可点击编辑的片段**呈现，而非一整坨黑盒。

### 用户旅程（核心闭环）
1. **导入数据**：CSV/XLSX/TSV/JSON → 自动类型推断 → 生成"数据摘要"（列名、dtype、统计量、前几行样例、缺失率）→ 在界面展示数据表
2. **告诉 AI 想画什么**：用户用自然语言描述（也可让 AI 自动推荐目标，参考 LIDA goals）
3. **AI 生成代码并执行**：选定图表类型 + 风格预设 → LLM 生成 matplotlib 代码 → 沙箱执行 → 图片即时预览
4. **多轮对话调整**："x 轴改成 log、柱子换个色、加误差棒、标题改英文" → LLM 只改相关代码段（diff 展示）
5. **代码定位与编辑**：代码按语句拆分为"片段卡"，每张卡有中文解释 + 常用参数表单（颜色/字号/标签…），点"编辑"直接改代码，改完重跑
6. **保存预设 / 历史**：会话与每个版本可保存；用户可把任意一段"代码片段"交给 AI 归纳成新预设

### 功能模块划分
| 模块 | 说明 | 参考 |
|---|---|---|
| M1 数据导入与摘要 | pandas 解析、类型推断、统计摘要、大文件采样 | LIDA summarize |
| M2 LLM 编排 | 统一 OpenAI 兼容接口（DeepSeek/OpenAI/通义/vLLM 本地）；上下文 = 数据摘要 + 当前代码 + 风格 + 历史；流式输出 | LIDA / llmx |
| M3 沙箱执行 | 本地 subprocess / Jupyter kernel，白名单库、超时、内存限制、输出 PNG/SVG；Windows 用 Job Object 防泄漏 | PlotCraft 沙箱渲染 |
| M4 预览与渲染 | matplotlib Agg 后端 → 图片回显；可选 plotly 交互渲染 | - |
| M5 代码定位与解释 | 用 ast 分析生成代码，语句级注释 + 行号高亮 + 参数表单化 | 本软件核心差异化 |
| M6 预设系统 | 克隆的风格包（SciencePlots 等）索引为元数据（缩略图/适用图型/颜色/字体）；用户可导入代码 → LLM 生成新预设 | AgentFigureGallery / skill 集合 |
| M7 历史与版本 | SQLite 存会话、每次生成的代码与图、可回退 | PlotCraft SQLite history |
| M8 导出 | PNG/SVG/PDF 300dpi、按期刊（tueplots 尺寸）导出 | - |

### 技术选型建议
- **前端**：React + TypeScript + Vite（可选 Tauri 打包成桌面应用）
- **后端**：Python FastAPI + uvicorn（和 matplotlib 生态天然衔接）
- **执行沙箱**：本地方案（对用户数据隐私友好）：subprocess + 资源限制；后续可升级 Docker
- **LLM**：OpenAI 兼容协议，任意 provider（国内用户默认 DeepSeek）；密钥本地存储（可选加密）
- **数据库**：SQLite
- **绘图**：matplotlib（出版级）+ SciencePlots 等预设；交互图用 plotly
- **代码定位**：Python ast + 模板匹配（ax.plot/plt.scatter 等语句级拆分）

### 界面布局草案
```
+--------------+----------------------+-----------------+
| 数据面板      | 预览画布（主）        | AI 对话（右栏）  |
| 列信息/摘要   | 图片 + 版本切换       | 聊天气泡+建议   |
| 预设选择卡片  | 代码定位面板（下）     |                 |
+--------------+----------------------+-----------------+
代码定位面板：片段卡列表（解释 + 参数表单 + 编辑按钮） + 行号高亮源码
```

### 风险与对策
- **LLM 代码错误率高** → 沙箱内自动重试修复（LIDA evaluate/repair 思路）；对生成代码做 AST 校验
- **沙箱安全**（LLM 生成任意代码）→ 白名单 import、禁止文件系统/网络、超时与资源限制
- **上下文超限**（大数据）→ 数据摘要化 + 采样；代码按片段独立管理
- **中文标注/字体** → SciencePlots 自带 CJK 支持；预设含字体兜底
- **用户导入的代码质量参差** → "导入→AI 结构化归纳为预设"流程兜底
